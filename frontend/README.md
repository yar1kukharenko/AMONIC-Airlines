Требования

- Node.js версии 12.22.0 или выше
- npm (устанавливается вместе с Node.js) или yarn

Установка

1. Склонируйте репозиторий
2. Установите зависимости

```bash
npm install
```

3. Запустите проект

```bash
npm run dev
```

4. Откройте [http://localhost:3000](http://localhost:3000) в вашем браузере


5. Пример страницы находится в `app/test/page.tsx`. Ее адрес
   будет [http://localhost:3000/test](http://localhost:3000/test)
